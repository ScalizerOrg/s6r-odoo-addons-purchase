Scalizer Purchase Order Amendment

s6r_purchase_order_amendment

This module tracks amendments (avenants) linked to a confirmed purchase order, so the origin order and its amendment(s) stay traceable in both directions.

Key Features

  • "Create Amendment" button available on confirmed purchase orders
  • The new amendment order is linked back to its origin order
  • Order name suffixed automatically (/AMDT-01, /AMDT-02, ...)
  • Smart button on the origin order to browse its amendments
